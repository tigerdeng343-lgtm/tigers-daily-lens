# Daily Post Generation Instructions

This file tells Rue how to generate the daily blog post.

## Process

1. **Fetch news** from these sources:
   - Reuters (finance, world)
   - AP News (general)
   - Yahoo Finance (markets)
   - TechCrunch (technology)
   - Defense News (defense/geopolitics)

2. **Analyze** the top 4-6 stories across categories:
   - 💰 Finance & Markets
   - 💻 Technology
   - 🛡️ Defense & Geopolitics
   - 🎭 Culture (if notable)

3. **For each story, provide:**
   - What happened (factual summary)
   - Why it matters (analysis)
   - Market implications (sectors, stocks)

4. **Create watchlist** with:
   - Ticker symbols
   - Direction (bullish/bearish/neutral)
   - Brief thesis

5. **Write the post** in markdown format

6. **Commit and push** to GitHub

## Schedule

Run daily at 7:00 AM EST

## Output

File: `_posts/YYYY-MM-DD-daily-lens.md`
